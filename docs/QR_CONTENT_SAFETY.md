# QR Content Safety Guide

QR codes can encode URLs, contact details, Wi-Fi credentials, plain text, or other data. Before sharing a generated code, review what it contains.

## Before creating a code

- Check the destination URL carefully, including the domain and spelling.
- Prefer HTTPS links for websites that support it.
- Avoid encoding passwords, private tokens, or confidential information into a QR code.
- For Wi-Fi QR codes, remember that anyone who scans the code may be able to join the network.

## Before publishing or printing

1. Scan the finished QR code with a trusted device.
2. Confirm that the decoded content matches what you intended.
3. Test the code at its final printed size and from a reasonable distance.
4. Keep a copy of the original destination or payload so you can update printed materials later.

## Troubleshooting scans

If a code does not scan reliably, try increasing its size, improving contrast, leaving a clear margin around it, and avoiding busy backgrounds or excessive logo overlays. Re-test after every design change.

A QR code only carries data; it does not make a destination safe. Treat unexpected links with the same caution as links received in messages or email.
